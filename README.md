# 🏠 House Price Prediction Model

## 📌 Project Overview
This project is a Machine Learning-based application that predicts house prices based on various input features such as area, number of bedrooms, and bathrooms. The model is trained using regression techniques to provide accurate price estimations.

---

## 🚀 Features
- Predicts house prices based on user inputs  
- Uses Machine Learning regression model  
- Simple and easy-to-use interface  
- Built using Python  

---

## 🛠️ Technologies Used
- Python  
- NumPy  
- Pandas  
- Scikit-learn  
- Flask (if you used it, otherwise remove this)

---

## 📊 How It Works
1. Data is collected and preprocessed  
2. Features like size, bedrooms, and bathrooms are used  
3. A regression model is trained on the dataset  
4. The model predicts the house price based on input values
